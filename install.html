Downloads & install

Get Torqz mods into BeamNG.drive in about a minute. No extra tools needed.

Downloads

Downloads appear here as soon as a mod is released.

    Install a mod

    BeamNG.drive loads mods straight from their .zip file.

    1. Download the .zip

      Grab the mod from the downloads list above. Keep it as a .zip and don't extract it.

    2. Open your BeamNG user folder

      In the BeamNG.drive launcher, choose Manage User Folder, then Open in Explorer.

    3. Go into your game version folder

      Open the folder named after your current game version (it's a version number). If there's no mods folder inside, create one.

    4. Drop the .zip into mods

      Drag the .zip file into the mods folder.

    5. Check it in-game

      Start BeamNG.drive and open the Mods Manager. The mod should be listed and turned on.

    Where the file goes

    Your folders should end up looking like this.

    • BeamNG.drive
    • your game version
    • mods
    • torqz-garage.zip here

    If something's not working

    The mod doesn't show up in the Mods Manager

    Make sure the .zip is directly inside the mods folder for your current game version, not in a subfolder and not extracted. Then restart the game.

    It shows up but doesn't do anything

    Open the Mods Manager and check the mod is turned on. If you have a lot of other mods, try turning them off to rule out a conflict.

    The game updated and the mod stopped working

    Game updates create a new version folder. Move the .zip into the mods folder of the new version, and check here for an updated release.
