About Torqz Mods

An independent BeamNG.drive modding project.

Torqz

BeamNG.drive modder

    I started Torqz Mods because I wanted to build BeamNG projects that add something useful to the game instead of just filling a download page.

    Each mod is built one feature at a time and tested in-game before it moves on. I share progress while I'm building, so you can see what's working, what's next, and help shape where it goes.

    Torqz Garage is the first project. More are coming.
